# 같이 개발해 봐요 | 클로드 코드로 신청 페이지
## 클로드 코드가 뭐예요?
- 말로 부탁하면 ==직접 코드를 짜고, 고치고, 올려 주는== AI 개발자
- 웹북 메이커도 클로드 코드와 함께 만들었습니다
- 오늘 만들 것: **가을 수련회 신청 페이지** (안내 + 신청 + 문자 보내기)

qr: https://webbook-kr.github.io/event/ | 완성 예시 | 먼저 폰으로 신청해 보세요

## 준비물 (처음 한 번)
- 클로드 **Pro 이상** 요금제 (무료는 안 됩니다)
- **깃허브(GitHub) 계정** — 무료 가입
- 깃허브에 빈 저장소 하나: 이름 `retreat`, **Public**, README 추가

::: 둘 중 하나라도 없으면 오늘은 화면을 보며 따라오세요

## 1. 새 대화 시작
- **claude.ai/code** 접속 (폰은 클로드 앱 **Code** 탭)
- 처음이면 **깃허브로 로그인** → 승인
- 입력창 아래에서 저장소 **retreat** 고르기
- 다음 쪽 프롬프트 ①을 붙여넣고 **Enter**

## 2. 프롬프트 네 번이면 끝
- **① 만들기** 안내 + 신청 칸 + 문자 보내기
- **② 고치기** 가을 색, 남은 날짜(D-몇 일)
- **③ 다듬기** 빈칸이면 빨갛게 알려 주기
- **④ 올리기** main에 합치고, 올리는 법 묻기

qr: https://webbook-kr.github.io/lab/code.html | 프롬프트 복사 페이지 | 단추 하나로 복사

## 3. 인터넷 주소 만들기
- 화면의 **Create PR** → 깃허브에서 **Merge**
- 저장소 **Settings → Pages**
- Branch **main**, **/ (root)** → **Save**
- 1~3분 뒤 나오는 주소를 단톡방에!

핵심: 코드를 몰라도, 원하는 것을 ==정확히 말하면== 만들어집니다

## 부탁 잘하는 법
- **누가 쓰나** "50대 이상도 보기 편하게"
- **무엇이 들어가나** 칸 이름을 하나씩 적기
- **누르면 어떻게** "신청하기를 누르면 문자 창이 열리게"
- **한 번에 하나씩** 고칠 점은 결과를 보고 한 가지씩
