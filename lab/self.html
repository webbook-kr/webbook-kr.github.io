내 손으로 웹북 만들기

남이 만든 도구 없이, 클로드에게 부탁해 내 웹북을 직접 만들고 링크로 나눠요.

준비물
  • 클로드 계정 (claude.ai · 구글 계정으로 로그인, 무료로 충분)
  • 내 자료: 설교 메모, 행사 안내, 간증… 없으면 아래 예시 자료
  • 노트북 권장 · 휴대폰도 됩니다

순서 (6단계)

  1. claude.ai 로그인 → 새 채팅
  2. 아래 ① 웹북 만들기 프롬프트 복사 → 채팅창에 붙여넣기
  3. 맨 아래 [자료] 밑 안내 문구를 지우고 내 자료 붙여넣기 → 보내기
  4. 오른쪽(휴대폰은 카드 누르기)에 웹북이 바로 나옴 → ‹ › 로 넘겨 보기
  5. 마음에 안 들면 ② 고치기 문장으로 말로 고치기
  6. 오른쪽 위 Publish(게시) → 링크 복사 → 카톡 단톡방에 붙여넣기
복사·붙여넣기
  • 윈도우: 복사 Ctrl+C · 붙여넣기 Ctrl+V
  • 맥: 복사 ⌘+C · 붙여넣기 ⌘+V
  • 휴대폰: 글자칸을 길게 눌러 ‘붙여넣기’

프롬프트

1

웹북 만들기

내 자료 → 넘겨 보는 웹북

아래 [자료]로 휴대폰에서 한 쪽씩 넘겨 보는 '웹북'을 만들어 줘. HTML 아티팩트 하나로 만들어 줘.

[웹북 모양]
- 첫 쪽은 표지: 책 제목, 부제, 날짜(또는 글쓴이)
- 둘째 쪽은 차례: 누르면 그 쪽으로 이동
- 한 쪽에는 소제목 1개와 짧은 항목 3~5개만. 넘치면 다음 쪽으로 나누기
- 화면 아래에 ‹ › 단추와 '3 / 12' 같은 쪽 번호. 손가락으로 좌우로 밀어도 넘어가게
- 휴대폰 세로 화면에 맞추고, 본문 글자는 18px 이상으로 크게 (50~70대도 읽기 편하게)
- 차분한 색 한 가지를 정해 제목과 강조에만 쓰기
- 마지막 쪽은 한 줄 정리 또는 나눔 질문

[원칙]
- 자료에 있는 내용만 쓰고, 없는 내용·숫자·이름은 지어내지 말 것
- 인사말·잡담은 빼고 핵심만
- 외부 라이브러리 없이 HTML 하나로
- [자료]가 비어 있으면 만들지 말고 '자료를 붙여 주세요'라고만 답할 것

[자료]
(여기에 내 메모·설교 요약·행사 안내를 붙여넣기)
내 자료가 없으면: 예시 자료가 들어간 프롬프트

하나 골라 복사해서 그대로 보내면 됩니다. (예시 내용)

2

고치기

같은 채팅에서 말로 부탁하기

  • 글자·분량 글자를 더 크게 하고, 한 쪽에 항목을 3개로 줄여 줘
  • 색·분위기 표지를 더 따뜻한 느낌으로 바꾸고, 색은 쪽빛(남색)으로 해 줘
  • 쪽 추가 3쪽 뒤에 '기도 제목' 쪽을 하나 추가해 줘: (여기에 기도 제목)
  • 영상·링크 마지막 쪽에 유튜브 영상으로 가는 큰 단추를 넣어 줘: (영상 주소)
  • 다시 확인 휴대폰에서 글이 잘리거나 넘치는 쪽이 없는지 확인하고 고쳐 줘

한 번에 하나씩 부탁하면 더 잘 고쳐요. 괄호 ( ) 안은 내 내용으로 바꾸세요.

3

덤 · 나만의 웹북 제작기

책 한 권이 아니라, 책을 찍어 내는 도구 만들기

글을 붙여넣으면 휴대폰으로 넘겨 보는 웹북이 되는 '나만의 웹북 제작기'를 HTML 아티팩트 하나로 만들어 줘.

[기능]
- 위쪽에 큰 글상자: 여기에 글을 붙여넣기 (처음 열면 예시 글이 들어 있게)
- 글 규칙: '# '로 시작하는 줄은 책 제목, '## '로 시작하는 줄은 새 쪽의 소제목, '- '는 항목, 그 밖의 줄은 본문
- '책 만들기' 단추를 누르면 아래에 웹북 미리보기: 표지, ‹ › 단추, 쪽 번호, 좌우로 밀기
- 색 고르기 3가지 (쪽빛·초록·주황)
- '웹북 파일 저장' 단추: 완성된 책을 HTML 파일 하나로 내려받기

[원칙]
- 휴대폰에서도 쓰기 편하게, 글자 크게
- 외부 라이브러리 없이 HTML 하나로
링크로 나누기 (Publish)
  • 웹북 화면 오른쪽 위 Publish(게시) → 한 번 더 Publish → 링크 복사
  • 링크를 받은 사람은 로그인 없이 바로 봅니다
  • 고친 뒤 다시 Publish 하면 같은 링크에 새 내용이 들어갑니다
  • 개인정보(전화번호·주소)는 넣지 마세요. 링크를 아는 사람은 누구나 볼 수 있어요
막힐 때
  • 웹북이 안 나오고 글만 나와요 → “HTML 아티팩트로 만들어 줘”라고 한 번 더
  • 너무 길어요 → “한 쪽에 항목 3개, 전체 10쪽 이내로”
  • Publish 단추가 안 보여요 → 웹북 카드를 눌러 크게 연 뒤 오른쪽 위 확인
  • 사용량 한도 → 몇 시간 뒤 다시, 또는 짝꿍 노트북으로 같이
