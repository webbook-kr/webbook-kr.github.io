클로드 코드로 신청 페이지 만들기

말로 부탁하면 AI가 코드를 짜고, 인터넷 주소까지 만들어 줍니다.

완성 예시 먼저 보기 ›

0. 준비 (처음 한 번)

필요한 것
  • 클로드 Pro 이상 유료 요금제 (무료는 클로드 코드를 못 씁니다)
  • 깃허브(GitHub) 계정 — github.com에서 무료 가입

둘 중 하나라도 없으면 오늘은 화면을 보면서 따라오시고, 완성된 페이지를 폰으로 써 보세요.

깃허브에 빈 저장소 만들기
  1. github.com 오른쪽 위 + → New repository
  2. 이름: retreat (영어로 아무거나)
  3. Public 선택, Add README 체크
  4. Create repository
클로드 코드 시작
  1. claude.ai/code 접속 (휴대폰은 클로드 앱의 Code 탭)
  2. 처음이면 깃허브로 로그인 → 승인
  3. 입력창 아래 저장소 선택에서 방금 만든 retreat 고르기
  4. 아래 ① 프롬프트를 붙여넣고 Enter

1~4. 프롬프트 (복사해서 붙여넣기)

1

만들기

새 대화에 그대로 붙여넣기

교회 가을 수련회 신청 페이지를 만들어 줘.

- index.html 파일 하나로, 휴대폰에서 보기 좋게
- 위쪽: 수련회 안내
  주제 "함께 걷는 길", 11월 22일(토)~23일(주일), ○○ 수양관
  준비물: 성경, 필기도구, 세면도구, 편한 운동화
  회비: 어른 5만원, 학생 3만원
- 아래쪽: 신청 칸
  이름, 연락처, 구역, 참석 일정(1박 2일 / 첫날만 / 둘째 날만), 차량 필요 여부, 하고 싶은 말
- "신청하기"를 누르면 담당자 번호(010-0000-0000)로 신청 내용이 적힌 문자 창이 열리게
- 문자가 안 되는 사람을 위해 "신청 내용 복사" 단추도
- 글씨는 크게, 50대 이상도 보기 편하게
2

고치기

결과를 보고 이어서 부탁

색을 가을 느낌(주황·갈색)으로 바꾸고, 맨 위에 수련회까지 남은 날짜(D-몇 일)를 크게 보여 줘.
3

다듬기

실수를 막는 장치

이름이나 연락처를 비워 두고 "신청하기"를 누르면, 빠진 칸을 빨갛게 표시하고 무엇이 빠졌는지 알려 줘.
4

올리기

인터넷 주소로 만들기

지금까지 만든 것을 main 브랜치에 합쳐 줘. 그리고 GitHub Pages로 인터넷에 올리려면 내가 화면에서 무엇을 눌러야 하는지 순서대로 알려 줘.

5. 인터넷 주소 만들기

  1. ④를 보낸 뒤 화면에 Create PR이 보이면 누르고, 깃허브에서 Merge pull request → Confirm
  2. 깃허브 저장소 → Settings → 왼쪽 Pages
  3. Branch를 main, 폴더 / (root)로 두고 Save
  4. 1~3분 뒤 위쪽에 나오는 주소가 내 페이지 → 단톡방에 공유!

주소 모양: https://내아이디.github.io/retreat/

막혔을 때
  • 클로드가 질문하며 멈추면 → 보기 중 하나를 고르면 이어서 합니다 (특히 ④ 올리기에서 "main에 바로 합칠까요?" 같은 확인)
  • 결과가 마음에 안 들면 → 고칠 점을 그냥 말로 다시 부탁
  • 오류가 났다 → 오류 화면을 그대로 복사해 붙이고 "고쳐 줘"
  • Pages에 주소가 안 뜬다 → 저장소가 Public인지 확인, 몇 분 더 기다리기
