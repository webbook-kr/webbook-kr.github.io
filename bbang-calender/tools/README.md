# 내 컴퓨터에서 일정 갱신하기

## 왜 필요한가

빵캘은 깃허브가 하루 두 번 저절로 일정을 모읍니다. 그런데 **공공기관 다섯 곳은 그 방식으로 못 가져옵니다.**

- 보건복지부
- 질병관리청
- 식품의약품안전처
- 한국건강증진개발원
- 국립중앙의료원

한국 공공기관 누리집이 해외 데이터센터 주소를 막기 때문입니다. 깃허브 서버는 미국에 있어 연결이 끊깁니다.
학회와 연구원은 막지 않아서 자동으로 잘 들어옵니다.

그래서 이 다섯 곳만은 **국내 인터넷에 연결된 컴퓨터**에서 가끔 돌려 주셔야 합니다.
한 번 돌리면 그때 모은 일정이 사이트에 그대로 올라갑니다.

한 곳이 실패해도 이미 모아 둔 일정은 지워지지 않습니다. 안 돌려도 사이트가 비지는 않습니다. 다만 새 일정이 안 들어올 뿐입니다.

## 처음 한 번만 준비하기

### 1. Node 설치

<https://nodejs.org> 에서 **LTS** 를 받아 설치합니다. 맥과 윈도우 모두 받아서 다음만 누르면 됩니다.

설치를 확인하는 명령입니다.

| | 명령 |
|---|---|
| 맥 (터미널) | `node -v` |
| 윈도우 (명령 프롬프트) | `node -v` |

`v20.` 처럼 번호가 나오면 된 것입니다.

### 2. 저장소 받기

| | 명령 |
|---|---|
| 맥 | `cd ~/Documents && git clone https://github.com/epibrief/epibrief.github.io` |
| 윈도우 | `cd %USERPROFILE%\Documents && git clone https://github.com/epibrief/epibrief.github.io` |

### 3. 이름과 메일 적어 두기 (처음 한 번)

| | 명령 |
|---|---|
| 맥 | `git config --global user.name "이름"` <br> `git config --global user.email "메일주소"` |
| 윈도우 | 같습니다 |

## 돌리기

받아 둔 폴더 안 `bbang-calender/tools/` 로 들어가서 두 번 누릅니다.

| | 파일 |
|---|---|
| 맥 | `빵캘-갱신.command` |
| 윈도우 | `빵캘-갱신.bat` |

맥에서는 **처음 한 번만** 그냥 두 번 눌러도 안 열립니다. 파일에 마우스 오른쪽 > **열기** 를 누르고, 뜨는 물음에 **열기** 를 다시 누르면 그다음부터는 두 번 눌러서 열립니다.

창이 뜨고 다섯 단계가 지나갑니다. 몇 분 걸립니다. 마지막에 담긴 행사 수가 나오면 끝입니다.

## 하루 한 번 저절로 돌게 걸어 두기

### 맥

터미널에서 `crontab -e` 를 치고 아래 한 줄을 넣습니다. 매일 아침 8시에 돕니다.

```
0 8 * * * cd ~/Documents/epibrief.github.io && /usr/local/bin/node scripts/bbang-calender/collect.mjs && /usr/local/bin/node scripts/bbang-calender/geocode.mjs && /usr/local/bin/node scripts/bbang-calender/ics.mjs && git add -A bbang-calender && git commit -m "빵캘 갱신" && git push
```

Node 가 어디 있는지는 `which node` 로 확인해 그 경로를 쓰세요. 애플 실리콘 맥은 보통 `/opt/homebrew/bin/node` 입니다.

저장하고 나가는 법은 `Esc` 를 누르고 `:wq` 를 친 뒤 `Enter` 입니다.

### 윈도우

**작업 스케줄러**를 엽니다. 시작 단추 옆 검색창에 "작업 스케줄러"를 치면 나옵니다.

1. 오른쪽에서 **기본 작업 만들기**
2. 이름에 `빵캘 갱신` 입력 > 다음
3. **매일** 고르고 > 다음 > 시작 시각을 오전 8시로 > 다음
4. **프로그램 시작** > 다음
5. 프로그램/스크립트 칸에 `빵캘-갱신.bat` 파일을 **찾아보기**로 지정 > 다음 > 마침

돌린 뒤 몇 분 지나 이 주소를 열어 보시면 됩니다.

<https://epibrief.github.io/bbang-calender/>

## 안 될 때

| 화면에 나오는 말 | 뜻과 할 일 |
|---|---|
| `Node 가 없습니다` | 1번 준비를 다시 하세요 |
| `최신 상태로 맞추는 중 문제가 생겼습니다` | 터미널이나 명령 프롬프트에서 `git status` 를 쳐 보세요. 고칠 것이 남아 있습니다 |
| `올리지 못했습니다` | 인터넷을 확인하고, 깃허브 로그인이 풀렸는지 보세요 |
| `[실패] 어느 기관: fetch failed` | 그 기관 누리집이 잠깐 안 되는 것입니다. 다음에 다시 돌리면 들어옵니다 |
