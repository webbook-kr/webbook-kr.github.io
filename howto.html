1

원고 만들기

녹취·자료 → AI 요청문 → .md 원고 → 제작기

단계 사진으로 보기 (7장)
  1. 제작기 주소로 들어갑니다 — webbook-kr.github.io/maker.html
  2. 원고가 없으면 'AI 요청문 복사'를 누릅니다
  3. 챗GPT·클로드 등 AI 대화창에 붙여넣고, [자료] 아래에 녹취·메모를 넣습니다
  4. 받은 답(원고)을 메모장에 붙여 .md 파일로 저장합니다
  5. 제작기로 돌아와 '원고 파일 불러오기'로 그 파일을 엽니다 (원고 칸에 붙여넣어도 됨)
  6. 원고는 기호로 씁니다 — # 장 · ## 쪽 · - 항목 · ==강조== · 핵심:
  7. 오른쪽 미리보기에 책 모양이 바로 나옵니다
2

제작과 미리보기

책 정보 · 책 모양 · 글 간격 · 쪽 확인

단계 사진으로 보기 (5장)
  1. 책 정보: 제목(| 로 줄바꿈)·글쓴이·부제·날짜·표지 그림 주소
  2. 책 모양: 업무 자료는 '쪽빛'
  3. 글 간격: 자료집은 '촘촘' — 한 쪽에 더 많이 들어갑니다
  4. 미리보기에서 ‹ › 로 넘기며 쪽마다 글이 잘리지 않는지 확인
  5. '새 창에서 보기'로 크게 확인 — 넘치는 쪽은 문장을 줄이거나 --- 로 나눕니다
3

발행

발행 코드 → 책 주소 · 수정 열쇠 · 다른 PC 연결

단계 사진으로 보기 (5장)
  1. 과 공용 발행 코드를 넣습니다 (담당자에게 따로 받기)
  2. '발행하기'를 누르면 책 주소가 나옵니다
  3. '주소 복사' → 카톡·메일로 공유. 제목과 표지가 미리보기에 뜹니다
  4. '수정 열쇠 보기' — 다른 PC에서 고칠 동료에게만 알려 줍니다
  5. 다른 PC에서는 '이어서 고치기'에 책 주소 끝부분과 열쇠를 넣고 '연결하기'
4

회람과 의견

검토자가 폰에서 쪽마다 의견 남기기

단계 사진으로 보기 (5장)
  1. 검토자는 카톡으로 받은 책 주소를 폰에서 엽니다
  2. 고칠 곳이 있는 쪽에서 아래 '의견' 단추를 누릅니다
  3. 이름·소속(필수)과 고칠 내용을 적고 보내기
  4. 보낸 의견은 담당자에게 바로 모입니다
  5. 검토자끼리는 '의견 보기' 주소(읽기 전용)로 서로의 의견을 봅니다
5

의견 반영

모아보기 → 원고 고치기(++ ++) → 다시 발행 → 반영 기록

단계 사진으로 보기 (6장)
  1. 담당자는 제작기 발행 결과의 '의견 모아보기'에서 쪽 순서로 확인합니다
  2. 원고를 고치고, 바뀐 곳을 ++ ++ 로 감쌉니다 (다음 차수는 +++ +++)
  3. 미리보기에 바뀐 곳이 노란 바탕으로 보입니다 (+++ 는 초록)
  4. '다시 발행 (같은 주소)' — 주소는 그대로, 내용만 바뀝니다
  5. 의견마다 '반영'과 한 줄 답변을 저장 → 검토자가 책 안 의견 창에서 그대로 봅니다
  6. 반영을 마치면 '다음 차수 회람 시작' → 이후 의견은 2차로 구분됩니다
6

최종본

최종본 켜기 → 다시 발행 → PDF·반영표 보관

단계 사진으로 보기 (6장)
  1. 의견이 더 없으면 '최종본'을 켭니다
  2. 바뀐 곳 표시만 빠지고 글은 그대로입니다
  3. '다시 발행' → 같은 주소가 최종본으로 바뀝니다
  4. PDF는 책 오른쪽 위 'PDF' 단추 → '인쇄로 PDF 저장'
  5. 의견 모아보기 '반영표 인쇄' → 검토 의견 반영표를 PDF로 저장
  6. 원고(.md)·PDF·반영표를 과 공유폴더 한 곳에 보관하면 끝
예시 화면은 시연용 책(○○과 회의 결과 공유 자료집)입니다. 발행 코드·수정 열쇠는 담당자에게 따로 받으세요.
