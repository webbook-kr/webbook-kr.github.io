4. 제작과 발행 (②③)

  • 원고 넣기 "원고 파일 불러오기"로 .md 열기 또는 원고 칸에 붙여넣기 → 오른쪽 미리보기에 바로 반영
  • 책 정보 제목(줄바꿈은 |), 부제, 날짜, 표지 그림 주소 · 책 모양 업무 자료는 "쪽빛", 글 간격 자료집은 "촘촘"
  • 쪽 확인 미리보기를 폰 크기로 넘겨 보며 글이 잘리는 쪽("아래로 밀면 더 있음")이 없게 문장을 줄이거나 ---로 나눔
  • 발행 발행 코드 입력 → "발행하기" → 나온 주소 복사. 카톡 미리보기 제목·표지는 1분쯤 뒤부터 보임
  • 원고는 그 브라우저에 자동 저장되지만, 원본 .md 파일을 공유폴더에도 꼭 저장

5. 회람과 의견 반영 (④⑤)

  • 회람 책 주소를 검토자에게 공유. 검토자는 쪽마다 "의견" 단추 → 이름·소속(필수)과 의견 입력
  • 확인 제작기 발행 결과의 "의견 모아보기"(담당자용) → 쪽 순서로 전체 의견. 검토자끼리는 읽기 전용 주소로 공유
  • 반영 원고(.md)를 고치고 제작기에서 "다시 발행 (같은 주소)" → 주소는 그대로, 내용만 바뀜
  • 기록 모아보기에서 의견마다 상태(반영·보류·미반영)와 한 줄 답변 저장 → 검토자가 책 안 의견 창에서 바로 확인
  • 다음 차수 반영을 마치면 "다음 차수 회람 시작" → 이후 의견은 2차·3차로 구분됨
  • 다른 PC에서 고칠 때 제작기 "이미 발행한 책을 이 PC에서 이어서 고치기"에 책 주소 끝부분과 수정 열쇠 입력 → "연결하기"
바뀐 곳 색 표시(노란·초록 바탕)와 반영표 PDF는 Claude에 "의견 반영해 줘 / 반영표 만들어 줘"로 요청하면 같은 형식으로 만들어 줌

6. 최종본과 배포 (⑥)

  • "표시 지우고 최종본" 요청 → 같은 주소가 최종본으로 바뀜. 수정 이력 쪽에 최종본 날짜 기록
  • PDF 책 오른쪽 위 "PDF ▾" → "인쇄로 PDF 저장" · 오프라인 파일은 인터넷 없이 열리는 HTML(메일 첨부용)
  • 보관: 최종 원고(.md 또는 .html) · PDF · 검토 의견 반영표를 공유폴더 한 곳에

8. 자주 생기는 일

  • 새 내용이 안 보임 새로고침. 카톡은 오른쪽 아래 ↻
  • 사진이 깨짐 올린 직후 1~2분 기다린 뒤 새로고침
