# 원고 보관함

웹북으로 만든 책의 원고를 여기에 둔다. 책 파일(html)은 발행하면 서버에 올라가지만,
**원고가 있어야 고쳐서 다시 낼 수 있다.** 원고가 원본이고 책은 결과물이다.

## 들어 있는 것

| 원고 | 쓰임 | 발행 주소 |
|---|---|---|
| `일터와-선교에서-웹북-만들기.md` | 3시간 교육 강의자료 | https://webbook-kr.github.io/b/?book-2ww4r7 |
| `2026-제1차-감염병-위기-사회대응-포럼.md` | 포럼 결과 자료집 — 발표 5건 + 세션 2 발제문 4건·토론 + 영상 시간 목차 (책 모양 **먹**, 표지 `img/forum-2026-1.jpg`, 그림 `img/forum/2026-1/`) | https://webbook-kr.github.io/b/?2026-1-gngr |

## 고쳐서 다시 내는 법

1. 원고를 고친다
2. 제작기(https://webbook-kr.github.io/maker.html)에 파일을 올린다
3. 책 모양을 원래대로 고른다 (강의자료는 **쪽빛**)
4. 발행 코드를 넣고 발행한다

같은 브라우저에서 발행하면 **같은 주소로 갱신**된다. 다른 컴퓨터에서 발행하면
새 주소가 생기므로, 주소를 지켜야 할 때는 처음 발행한 컴퓨터에서 한다.
