# 제24차 가을 글로벌 특별새벽부흥회 설교 모음 (웹북)

- 책 주소: https://webbook-kr.github.io/b/24-uutn/
- 원재료: 사랑의교회 유튜브 재생목록(PLKoLR1YJzk7M) 10편의 자동 자막, 특새 뉴스레터 6호(기도 제목·강단 아카이브), 특새 홈페이지 찬양 목록(찬양목록.tsv)
- days.py: 날마다 기도 제목·함께 전한 말씀 요약·찬양 날짜 / 표지: img/teukse-2026/banner.jpg
- s0N-설교자.md: 설교별 요약 원고 (01·03·05·07·09 = 본설교)
- build.py: 설교 원고 + 집회 안내 + 함께 전한 말씀 → 한 권 원고
- pack.mjs + repage.py: 폰 화면(360×670)에서 문단 높이를 재어 쪽 나눔(---) 위치를 정함
  1. `python3 build.py`
  2. 제작기를 LIMIT 크게 한 사본으로 열어 긴 쪽 책을 만든 뒤 `node pack.mjs 360 670 긴책.html > pack.json`
  3. `python3 repage.py 제24차-가을-글로벌-특별새벽부흥회.md pack.json 제24차-가을-글로벌-특별새벽부흥회-쪽맞춤.md`
  4. 쪽맞춤 원고를 제작기(책 모양: 쪽빛)에 넣고 발행
- 해외 설교자 5편 요약은 뉴스레터 '강단 아카이브'·'설교 어록' 기준. 10.24(토) 풀 콘서트는 영상·찬양 목록 미공개
