# 전자책 계획 · 일터와 선교에서 웹북 만들기

강의자료(`일터와-선교에서-웹북-만들기.md`)를 나중에 전자책으로 늘린다.
지금은 계획만 적어 둔다. 작업은 교육이 끝난 뒤.

## 왜 늘려야 하나

강의자료는 **강사가 옆에 있는 것을 전제로** 썼다. 47쪽이고, 실습은 현장에서 채운다.
전자책은 혼자 읽는 사람이 끝까지 갈 수 있어야 하므로, 강사가 말로 하던 부분을
글로 채워야 한다. 목표 80~120쪽.

## 늘려야 할 곳

| 강의자료 | 전자책에서는 |
|---|---|
| 3부 실습 (강사가 시연) | 화면 그림 붙여 한 걸음씩 |
| 원고 문법 두 쪽 | 문법 한 장 전체로 |
| 질의응답 두 쪽 | 실제 교육에서 나온 질문으로 |

## 새로 넣을 장

- **막혔을 때** — 실제로 사람들이 막히는 자리 모음. 교육 현장에서 관찰해 둘 것
- **원고를 AI에게 맡기는 법** — 어떻게 말해야 쓸 만한 원고가 나오는지. 실제 지시문 예시
- **사례 다섯** — 기도편지, 매뉴얼, 설교 요약, 팀 핸드북, 제안서. 각각 원고와 결과를 나란히
- **맥과 윈도우 차이** — 인쇄, 파일 열기, 파일 위치가 다른 곳만 모아서

## 교육 끝나고 꼭 챙길 것

교육이 전자책의 재료다. 그날 반드시 적어 둔다.

1. 참석자가 **어디서 막혔는지** (말로 물어본 것 전부)
2. 참석자가 **무엇을 만들었는지** (사례로 쓸 것, 허락받기)
3. 시간이 모자란 대목과 남은 대목
4. "이것도 되나요?" 질문 목록

::: 교육 직후 30분 안에 적을 것. 하루 지나면 절반이 날아간다.

## 형식

- 웹북으로 먼저 낸다 (바로 나눌 수 있다)
- PDF는 웹북에서 그대로 뽑는다
- 서점 유통은 그다음. 웹북은 HTML 이라 서점에 그대로 올라가지 않는다.
  PDF 를 받아 주는 곳과 EPUB 만 받는 곳이 다르므로, 낼 때 가서 확인한다
