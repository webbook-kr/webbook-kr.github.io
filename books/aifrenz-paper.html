01 이 기록에 대하여4

정리한 방식과 한계

이 기록은 발표에서 다룬 paper-curation 도구의 공개 문서를 바탕으로 정리했습니다. 출처는 github.com/jehyunlee/paper-curation 입니다.

발표자가 현장에서 덧붙인 말, 질의응답, 시연 장면은 아직 채워지지 않았습니다. 영상 자막을 넣으면 그 부분이 채워집니다.

시간 목차의 시각도 아직 채워지지 않았습니다. 실제 시각을 넣으면 눌러서 그 지점으로 갈 수 있습니다.

무엇을 푸는가

02 무엇을 푸는가6

논문이 너무 많다

연구자에게 논문은 늘 밀립니다. 저장해 둔 PDF는 쌓이는데 읽은 것은 몇 편 안 됩니다. 문제는 읽는 속도가 아니라 무엇을 읽을지 고르는 일에 있습니다.

paper-curation은 그 고르는 일을 자동으로 처리합니다. 논문을 모으고, 한국어로 요약하고, 주제별로 묶고, 검색되는 웹사이트로 만들어 줍니다.

다 읽으려 하지 말고, 읽을 것을 고르는 데 힘을 쓰자.
02 무엇을 푸는가7

세 갈래 사용법

쓰는 사람에 따라 필요한 준비가 다릅니다.

갈래하는 일준비물
읽기만들어진 리뷰를 보고 검색없음
AI내 PDF로 리뷰 생성API 키 (선택)
수집전체 큐레이션 자동화Zotero, 여러 API

기본 설치는 API 키가 없어도 됩니다. 만들어진 결과를 보는 것부터 시작할 수 있습니다.

일곱 단계

03 일곱 단계9

모으고 요약하기

1. 데이터 수집 — 조테로(Zotero)에 담아 둔 논문에서 PDF를 꺼내 옵니다. 평소 쓰던 논문 관리 도구를 그대로 씁니다.

2. 구조화 리뷰 — 논문마다 여섯 개 항목으로 나눈 한국어 리뷰를 만듭니다. 줄글 요약이 아니라 항목이 정해진 형식이라, 논문끼리 비교가 됩니다.

3. 인용 분석 — 이 논문이 누구를 인용했고 누구에게 인용됐는지 모읍니다.

03 일곱 단계10

묶고 잇기

4. 토픽 모델링 — 논문을 주제별로 자동 분류합니다. 여기서 LLM을 쓰지 않고 SPECTER2와 HDBSCAN이라는 방법을 씁니다. 비용이 0원입니다.

5. 관계 추출 — "같이 보면 좋은 논문"을 이어 줍니다.

6. 딥 리서치 — 키워드 검색과 의미 검색을 함께 쓰는 색인을 만듭니다. 질문을 던지면 근거가 되는 논문을 짚어 줍니다.

7. 배포 — 정적 웹사이트로 만들어 올립니다.

무엇이 나오는가

04 무엇이 나오는가12

결과물

  • 한국어 리뷰 페이지 — 논문마다 구조화된 요약
  • 검색되는 웹사이트 — 키워드와 의미 검색 모두
  • 타임라인 — 분야별로 연구가 어떻게 흘러왔는지
  • 질의응답 — 근거 논문을 짚어 주는 답변
  • 팟캐스트 — 음성으로 만든 요약 파일

읽는 사람이 자기 API 키를 넣어 질의응답을 쓰는 구조입니다. 만든 사람이 비용을 다 떠안지 않습니다.

04 무엇이 나오는가13

드는 비용

항목비용
리뷰 한 편약 $0.05 ~ $0.15
월 20편 기준약 $10 ~ $20

분류에 LLM을 쓰지 않은 것이 비용을 낮춘 지점입니다. 요약에만 쓰고, 묶는 일은 다른 방법으로 처리했습니다.

배울 점

05 배울 점15

이 구조가 주는 교훈

자동화의 요령은 "전부 AI에게"가 아니라 "AI가 잘하는 곳에만"입니다.

이 도구에서 LLM은 요약 한 군데에만 쓰입니다. 분류는 통계적 방법으로, 검색은 색인으로, 배포는 정적 사이트로 처리했습니다. 그래서 논문이 늘어도 비용이 크게 늘지 않습니다.

비싼 도구를 어디에 쓸지 정하는 것이 설계입니다.
05 배울 점16

내 일에 옮긴다면

논문이 아니어도 같은 틀이 됩니다.

  • 모으기 — 흩어진 자료를 한곳에
  • 요약 — 정해진 항목으로 (줄글 말고)
  • 묶기 — 주제별 자동 분류
  • 찾기 — 검색되게
  • 내보내기 — 남이 볼 수 있는 형태로

뉴스 클리핑, 고객 문의, 회의록에도 그대로 적용됩니다.

이 기록을 채우는 법

  1. 유튜브에서 영상을 열고 더보기 → 스크립트 표시

- ## 으로 주제별 쪽을 나눌 것

- 시간 목차는 "12:30 내용" 형식
- 질의응답은 "Q:" 다음 줄에 "A:"
- 원문을 옮기지 말고 요약할 것
