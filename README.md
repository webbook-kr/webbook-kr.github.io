# 웹북 (webbook)

글만 있으면 넘겨 읽는 전자책이 되는 제작기. 서버도 설치도 없이 HTML 파일 하나가 책 한 권입니다.

- **안내서(첫 화면)** `index.html` — 화면 사진으로 따라 하는 사용법
- **제작기** `maker.html` — 마크다운을 넣으면 책이 나옵니다
- **책 틀** `template.html` — 제작기가 읽어서 책을 조립하는 원본
- **읽기 페이지** `b/책주소/index.html` — 발행 함수가 책마다 만들어 올림 (`/b/책주소/`). 카톡·문자로 나누면 제목·표지가 미리보기에 뜸. 틀은 `b/_book.html`, 손으로 만들 땐 `scripts/book_page.py`
- **예비 읽기 페이지** `b/index.html` (`/b/?책주소`) 와 `404.html` — 책 페이지가 아직 없을 때(발행 직후, 토큰 없음) 대신 책을 열어 줌
- **예시 책** `books/`

## 원고 표기

| 표기 | 결과 |
|---|---|
| `# 제목` | 새 장 (표지·차례 자동) |
| `## 소제목` / `---` | 새 쪽 |
| `**굵게**`, `> 인용`, `- 목록`, 표, ``` 코드, `![](주소)` | 그대로 |
| `youtube: 영상ID` | 누르면 재생되는 영상 |
| `::: 한 줄` | 메모 상자 |
| `qr: 주소` | QR 코드. 찍으면 바로 열립니다 |

제작기의 **책 모양**에서 색과 글꼴 조합 6가지 중 고를 수 있습니다. 한지, 먹, 쪽빛, 숲, 노트, 밤.
| `# 제목 \| 부제` | 챕터 표지와 차례에 설명 한 줄 |
| 책 정보의 `표지 그림 주소` | 책 표지 제목 위에 포스터·사진 |
| 책 정보의 `글 간격: 촘촘` (원고 머리 `간격: 촘촘`) | 줄 간격을 좁혀 한 쪽에 더 많이. 자료집·요약본에 |

제목 뒤 빈 줄은 있어도 없어도 같습니다. 빈 줄만 있는 자리는 쪽으로 만들지 않습니다.

### 세미나·강연 정리

| 표기 | 결과 |
|---|---|
| `발표자: 이름 \| 소속 \| 시간` | 발표자 정보칸 |
| `머리글: 세션 2 · 패널 토론` | 그 쪽부터 장 끝까지 쪽 맨 위에 작은 표시 (토론·부록처럼 성격이 다른 부분을 알림). `머리글:` 만 쓰면 끔 |
| `==핵심 구절==` | 다른 색 글자로 강조 (`**굵게**` 와 구분) |
| `핵심: 한 줄` | 결론 강조 상자 |
| `Q: 질문` + `A: 답변` | 질의응답 카드 (`-- 이름` 으로 말한 사람) |
| `12:30 내용` | 시간 목차. 누르면 영상이 그 지점부터 |
| 문장 속 `(37:20)` | 글 안의 시간 링크 |

## 발행

제작기의 **발행하기**에 발행 코드를 넣으면 주소가 생깁니다. 책 파일은 수파베이스 저장소에 올라가고 `b/index.html` 이 받아서 보여줍니다.

- 발행 함수 소스: `functions/webbook-publish/`
- 발행 코드 관리: 수파베이스 → Table Editor → `webbook_codes`

## 잠그기

`scripts/lock_ebook.mjs` 로 본문과 PDF를 코드로 암호화합니다. 브라우저에서 코드를 넣으면 풀립니다.

```
node scripts/lock_ebook.mjs drafts/book1.html "코드"
```
