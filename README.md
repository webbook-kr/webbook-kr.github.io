# 웹북 (webbook)

글만 있으면 넘겨 읽는 전자책이 되는 제작기. 서버도 설치도 없이 HTML 파일 하나가 책 한 권입니다.

- **안내서(첫 화면)** `index.html` — 화면 사진으로 따라 하는 사용법
- **제작기** `maker.html` — 마크다운을 넣으면 책이 나옵니다
- **책 틀** `template.html` — 제작기가 읽어서 책을 조립하는 원본
- **읽기 페이지** `b/index.html` — 발행된 책을 여는 곳 (`/b/?책주소`)
- **예시 책** `books/`

## 원고 표기

| 표기 | 결과 |
|---|---|
| `# 제목` | 새 장 (표지·차례 자동) |
| `## 소제목` / `---` | 새 쪽 |
| `**굵게**`, `> 인용`, `- 목록`, 표, ``` 코드, `![](주소)` | 그대로 |
| `youtube: 영상ID` | 누르면 재생되는 영상 |
| `::: 한 줄` | 메모 상자 |

### 세미나·강연 정리

| 표기 | 결과 |
|---|---|
| `발표자: 이름 \| 소속 \| 시간` | 발표자 정보칸 |
| `핵심: 한 줄` | 결론 강조 상자 |
| `Q: 질문` + `A: 답변` | 질의응답 카드 (`-- 이름` 으로 말한 사람) |
| `12:30 내용` | 시간 목차. 누르면 영상이 그 지점부터 |
| 문장 속 `(37:20)` | 글 안의 시간 링크 |

## 발행

제작기의 **발행하기**에 발행 코드를 넣으면 주소가 생깁니다. 책 파일은 수파베이스 저장소에 올라가고 `b/index.html` 이 받아서 보여줍니다.

- 발행 함수 소스: `functions/webbook-publish/`
- 발행 코드 관리: 수파베이스 → Table Editor → `webbook_codes`

## 잠그기

`scripts/lock_ebook.mjs` 로 본문과 PDF를 코드로 암호화합니다. 브라우저에서 코드를 넣으면 풀립니다.

```
node scripts/lock_ebook.mjs drafts/book1.html "코드"
```
